# Expense Tracker

A React-based Expense Tracker app to manage monthly expenses and budgets.

## Features

- Select a month
- Set budget for selected month
- Add expenses with name, amount, category, and date
- Edit expenses
- Delete expenses with confirmation
- Search expenses
- Category-wise expense breakdown
- Budget progress bar
- Budget exceeded warning
- Data saved in browser using LocalStorage
- Responsive UI

## Tech Stack

- React
- JavaScript
- CSS
- Vite

## How to Run

```bash
npm install
npm run dev
```

Then open the localhost link shown in terminal.

Example:

```txt
http://localhost:5173/
```

## How to Use

1. Select a month.
2. Enter budget for that month.
3. Add expenses with name, amount, category, and date.
4. View total spent, remaining budget, and category-wise spending.
5. Search, edit, or delete expenses when needed.
